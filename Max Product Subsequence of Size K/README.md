### 📝 Problem Statement

Given an array arr[] of integers and an integer k, find a subsequence of size k whose product is maximum among all possible subsequences of size k. Return the maximum product that can be obtained.Examples:

### Input:
 arr[] = [1, 2, 0, 3], k = 2


### Output:
 6


### Explanation:
 Subsequence containing elements {2, 3} gives maximum product: 2*3 = 6

### Input:
 arr[] = [1, 2, -1, -3, -6, 4], k = 4


### Output:
 144


### Explanation:
 Subsequence containing {2, -3, -6, 4} gives maximum product: 2*(-3)*(-6)*4 = 144
