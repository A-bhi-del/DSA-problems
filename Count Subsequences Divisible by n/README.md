### 📝 Problem Statement

Given a numeric string s containing only digits and an integer n, count the number of non-empty subsequences of s whose numeric value is divisible by n. Return the answer modulo 1e9 + 7.
Examples:


### Input:
 s = "1234", n = 4


### Output:
 4


### Explanation:
 The subsequences 4, 12, 24 and 124 are divisible by 4.


### Input:
 s = "330", n = 6


### Output:
 4


### Explanation:
 The subsequences 30, 30, 330 and 0 are divisible by 6.



### Constraints:
1 ≤ |s| * n ≤ 106
